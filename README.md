# Taylor Brothers Hot Dog Stand Website

Restaurant: Taylor Brothers Hot Dog Stand, Visalia, CA
Student: Edward Contreras
Class: Web Design

 About the restaurant
Taylor Brothers is a family run hot dog stand in Visalia that has been serving chili dogs since 1952. It runs on a walk-up window, a simple menu and low prices.

About this project
This is my final project for my web design class. I am creating a website for the stand with 4 pages, that work on mobile and desktop. It has a retro red, cream and mustard look based on the stand's vintage sign.

 Technologies
- HTML
- CSS
- JavaScript
- Bootstrap
